Woody Ornamentals — photo bundle

photos/          upload this whole folder into /hrt/ on the server
photos.js.txt    RENAME to photos.js first, then upload into /hrt/ beside index.html

(Named .txt in this zip on purpose — browsers block downloaded .js files as
a security precaution. Renaming a file already on your disk is fine; only the
download itself gets flagged.)

index.html and sheets.html already contain <script src="photos.js">, so no
HTML edit is needed — just get the renamed file into /hrt/.

EXIF metadata has been removed from every JPEG in this bundle.
Images held back as Unsure are not included.
